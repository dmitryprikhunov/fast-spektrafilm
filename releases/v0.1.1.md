Numerical parity fixes and lower working memory for the Rust CLI and Slint
desktop app, using the same pinned experimental processing model and original
measurement assets.

- Correct camera lens-blur/diffusion order and preserve batch arithmetic when
  building inverse LUTs, including even and odd grid sizes.
- Choose one render seed consistently across conversion routes and executors;
  unseeded conversion glare now varies between renders.
- Reuse bounded preparation caches and FFT scratch, reduce spatial and inverse
  solver allocations, and retain the reference float32 grain working stores.
- Reuse GUI preparation and resolved settings for preview/scan cache keys.
- Add strict numerical contracts, shared-input interaction fixtures and a
  scheduled/on-demand pinned Python differential workflow. All 35 interaction
  cases, 129 stage golden arrays and 20 Gaussian golden arrays are retained.

The pinned reference sweep passed 590 stage/decoder comparisons, including ten
bitwise grain comparisons. On the 64px optical stress probe, RGB maximum error
fell from 0.00429285 to 8.38518e-9; the 32³ inverse-LUT CMY discrepancy is now zero.
On a measured 256px crop, inverse-solver additional live storage fell from
9.75 to 5.25 MiB, and grain from 4.625 to 2.317 MiB. These crop measurements do
not establish full-frame peak memory. Diffusion retains its explicit float32
FFT precision allowance. Small-preview scratch reuse reduces allocations but
showed no latency gain on the measured probe.
