Preview navigation, parameter editing and processing-status improvements for
the Rust CLI and Slint desktop app.

- Zoom toward the pointer with the mouse wheel and pan with the left mouse
  button. Original, Processed and Compare share zoom and pan; Fit and the
  pixel-scale presets center the image.
- Adjust numeric fields, dropdowns and checkboxes with the wheel. Numeric
  steps and bounds follow the pinned reference GUI. Pending text is validated
  before stepping, invalid entries stay editable, and partial wheel movements
  survive parameter refreshes.
- Move compact clockwise/counterclockwise rotation icons beside the zoom
  controls, available from every tab.
- Add delayed, wrapped reference tooltips over labels, fields and checkboxes.
  Group controls in the reference order, including nested Grain sections;
  Automatic preview and Workflow remain available in the footer.
- Show queued and active processing status consistently, including while
  saving settings or reporting an invalid entry. Middle/right mouse drags
  no longer jump the preview.

The processing model remains pinned to experimental spektrafilm commit
`28bf883e1672e884307edc75852549376e13644e`, with the original measurement assets
and licenses. Validation includes 54 release tests, native Slint input-event
regressions, strict float64 reference comparisons and all 235 asset hashes.
Four optional/native/benchmark checks are excluded from the normal local run;
CI separately exercises Lensfun and metadata support.

Download **fast-spektrafilm-0.1.2-linux-x86_64.tar.gz** for both executables,
original film/filter/LUT/ICC data and licenses. The matching
**fast-spektrafilm-0.1.2-source.tar.gz** contains the source, Cargo.lock and pinned
LibRaw; **SHA256SUMS** verifies both archives. Linux x86_64 / glibc 2.39+ remains
the supported binary target. See **RELEASES.md** in the archive for runtime
dependencies and setup.
