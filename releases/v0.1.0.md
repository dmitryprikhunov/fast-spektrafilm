First release of the Rust CLI and Slint desktop darkroom, based on spektrafilm's
pinned experimental processing model.

- RAW and RGB input; film, print, negative conversion and original optical filters.
- Preview, full-resolution Scan and cached Save in the desktop app; shared JSON settings with the CLI.
- PNG, JPEG, TIFF, EXR and float64 NPY output, ICC profiles and optional native metadata/lens correction.
- Audit D1–D9 closed; pinned reference comparisons cover processing stages, calibration, preview resizing and file output.
- Cargo CI builds/tests the library, CLI and GUI and explicitly exercises native Lensfun and metadata paths.

Download **fast-spektrafilm-0.1.0-linux-x86_64.tar.gz** for both executables,
original measurement/LUT/ICC data and licenses. The matching **source.tar.gz**
contains Rust sources, Cargo.lock and pinned LibRaw; **SHA256SUMS** verifies both
archives. See **RELEASES.md** inside the archive for setup and runtime libraries.

Linux x86_64 / glibc 2.39+ is the supported binary target. Full-resolution
negative conversion and diffusion can be slow and memory-intensive: the measured
22.4 MP diffusion scan used about **5.8 GiB RSS**. GUI scan work runs in a worker;
preview and scan timing depends on settings and image size. See BENCHMARKS.md and
MIGRATION.md for measured accuracy, performance and compatibility boundaries.

GPLv3; original spektrafilm attribution and third-party notices are retained.
